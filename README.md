# AI Dashboard – Flights Dataset

## Project Overview

This project is an AI Dashboard created using the Flights Dataset in Jupyter Notebook. The dashboard analyzes passenger trends over different years and months using data visualization and interactive filtering.

## Dataset

Dataset Used: Flights Dataset

Dataset Link:
https://raw.githubusercontent.com/mwaskom/seaborn-data/master/flights.csv

## Features

* Dataset Overview
* Data Cleaning
* Key Performance Indicators (KPIs)
* 5 Visualizations
* Interactive Filter using Dropdown

## KPIs

* Total Records
* Total Years
* Total Months
* Average Passengers
* Maximum Passengers

## Visualizations

1. Year-wise Passenger Trend
2. Monthly Passenger Count
3. Passenger Distribution
4. Top 10 Highest Passenger Months
5. Year-wise Average Passengers

## Technologies Used

* Python
* Pandas
* Matplotlib
* ipywidgets
* Jupyter Notebook

## Instructions to Run the Project

1. Open Jupyter Notebook.
2. Install required libraries:
   pip install pandas matplotlib ipywidgets
3. Open the notebook file.
4. Run all cells step by step.
5. View charts and interactive filter.
